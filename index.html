    Teacher notes

    Each set practises one skill area from the Reading & Writing paper. Use a set as a 10–15 minute warm-up, a homework check, or a screen-shared discussion in an online lesson.

    SetSkill practisedExam-style link

    In an online lesson

    • Before: share the set link. Students read the text first, without the questions.
    • During: students answer alone, then the class discusses the distractors. Each explanation names the trap.
    • After: students copy their result slip into the class chat, so you can see which skills need more work.
    • Extension: after "Write It Right", students write the full email, article or review themselves.

    Check before teaching: exercise numbers, word counts and mark schemes can change between syllabus years. Match each set to the current Cambridge 0510 syllabus and specimen papers. The multiple-choice format here practises the reading skill. In the real exam, some tasks need short written answers.
