# ESL Skills Sampler · IGCSE edition

Exam-style reading and writing practice for learners of **Cambridge IGCSE English as a Second Language (0510)**. There are five skill sets, 40 questions, original texts, a hint for every question, and an explanation that names the trap. Everything lives in **one `index.html` file**: no build step, no framework, no backend.

A sibling of [MUET Vocab Quest](https://github.com/IzaninSofya/muet-vocab-quest-form6), with the same buddies.

## The five sets

| # | Set | Skill | Exam-style link |
|---|---|---|---|
| 1 | The Summer Reading Challenge | Reading: finding specific details | Short-answer comprehension |
| 2 | Learning Something New | Reading: matching across texts | Multiple matching (four people, A–D) |
| 3 | The Turtle Guardians | Reading: completing notes | Note completion from a longer article |
| 4 | Our Phone-Free School Day | Reading: opinions, attitudes & word meaning | Multiple choice on attitudes; meaning from context |
| 5 | Write It Right | Writing: purpose, audience & register | Email, report, article, review and essay conventions |

The multiple-choice format practises each reading skill. In the real exam, some of these tasks need short written answers.

## Features

- The reading text sits beside the questions on desktop, and folds away on phones after the first question
- Hints, explanations and a full review with **Retry my mistakes**
- **Result slips:** students add their name and class, then copy a summary for their teacher
- **Teacher notes** with a skill map and a plan for using a set in an online lesson
- Light and dark mode; keyboard: `A`–`D` answer, `H` hint, `T` show or hide text, `Enter` next
- Link straight to a set with `#set-1` … `#set-5`
- Self-test: open with `?test` to check the question bank

## Run or deploy

Open `index.html` in a browser. To publish, push it to a GitHub repo and turn on **Settings → Pages → Deploy from branch → main / root**.

## Privacy

Scores, name and class are saved in this browser only (localStorage). Nothing is sent anywhere.
